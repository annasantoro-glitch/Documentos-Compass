# Repositório de Materiais de QA e Testes

Este repositório reúne os principais arquivos e materiais produzidos durante meu estágio em **Quality Assurance (QA)** na **Compass UOL**, com foco em testes de software, automação e práticas de qualidade. Ele reflete minha trajetória de aprendizado, desde o entendimento de fundamentos teóricos até a aplicação prática em projetos reais — incluindo desafios técnicos, code reviews e uso de ferramentas essenciais para o QA moderno.

## Sobre a Jornada de Aprendizado

Durante o estágio, evoluí de conceitos básicos para habilidades avançadas em QA, explorando metodologias ágeis, criação de histórias de usuário, testes manuais, técnicas de priorização, testes exploratórios, automação com Robot Framework, API testing e práticas em cloud computing. Cada Sprint trouxe novos aprendizados e desafios, e o repositório foi sendo atualizado para refletir esse progresso.

---

## Resumo das Atividades por Sprint

### 🌀 Sprint 1  
**Temas:** Metodologias Ágeis, User Stories e Refinamento de Requisitos  
**Atividades:** Criação de User Story (Squad), Mapa Mental da User Story Ideal  

### 🌀 Sprint 2  
**Temas:** Testes de Software, Garantia da Qualidade, AWS (Amazon Q Business, Q Developer, Bedrock)  
**Atividades:** Plano de Testes para a aplicação ServeRest, Slides sobre Testes Estáticos (Squad)  

### 🌀 Sprint 3  
**Temas:** Testes Baseados em Risco, Priorização, Report de Bugs no Jira, Mapeamento de Aplicações  
**Atividades:** Report Individual de Bugs, Mapa Mental da aplicação Demoblaze, Planejamento e Documentação de Testes Exploratórios  

### 🌀 Sprint 4  
**Temas:** Testes de APIs, Postman, Swagger (PetStore), Mapeamento de Issues  
**Atividades:** Mapa Mental da API PetStore, Collection Postman, Report de Bugs, Challenge com API ServeRest (Plano de Testes, Collection e Mapa Mental)  

### 🌀 Sprint 5  
**Temas:** Git, GitHub, Python, Pytest, Automação de APIs com Robot Framework  
**Atividades:** Criação de Calculadora em Python com TDD, Automação da API Restful Booker com Robot Framework, Relatório de Code Review  

### 🌀 Sprint 6  
**Temas:** AWS EC2, Amazon Q Power Up, Robot Framework para APIs e Cloud Computing  
**Atividades:** Evolução dos testes na Restful Booker + Relatório de Execução, Deploy da API ServeRest em instância EC2, Challenge 2 [em andamento]  

### 🌀 Sprint 7  
**Temas:** Mapeamento de Elementos Web e Automação Web End-to-End com Robot Framework  
**Atividades:**  
- Estratégias de mapeamento no site `challenging_dom` (em Squad)  
- Mapeamento individual de elementos no site Demoblaze  
- Exercícios de identificação e validação de elementos nos sites `livelo.com`, `divvino.com` e `google.com`  
- Desenvolvimento e execução de um fluxo completo de testes End-to-End com Robot Framework  
- Utilização do estilo de relatório **Mark85** e ambiente configurado com **Node 18**

## Sobre os Arquivos

Este repositório contém:

- **Documentos de Planejamento de Testes:** planos detalhados para diferentes aplicações e desafios.
- **Sessões de Testes Exploratórios:** documentação estruturada de testes manuais e exploratórios.
- **Mapas Mentais:** representações visuais que apoiam a compreensão e organização de ideias.
- **Collections Postman:** arquivos para testes de APIs RESTful (ex: PetStore, ServeRest).
- **Relatórios de Bugs:** registros estruturados de defeitos encontrados durante as atividades.
- **Automação com Robot Framework:** projetos de testes automatizados em APIs RESTful e aplicações Web.
- **Relatórios de Code Review:** análises críticas aplicando boas práticas de QA.
- **Cloud + QA:** relatórios e evidências de execução de testes automatizados em ambientes na AWS EC2.
- **Outros Materiais Complementares:** slides, esquemas, scripts e anotações.
