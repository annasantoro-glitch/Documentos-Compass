## Resumo das Atividades

### 🌀 Sprint 1  
**Temas:** Metodologias Ágeis, User Stories e Refinamento de Requisitos  
**Atividades:** Criação de User Story (Squad), Mapa Mental da User Story Ideal  

### 🌀 Sprint 2  
**Temas:** Testes de Software, Garantia da Qualidade, AWS (Amazon Q Business, Q Developer, Bedrock)  
**Atividades:** Plano de Testes para a aplicação ServeRest, Slides sobre Testes Estáticos (Squad)  

### 🌀 Sprint 3  
**Temas:** Testes Baseados em Risco, Priorização, Report de Bugs no Jira, Mapeamento de Aplicações  
**Atividades:** Report Individual de Bugs, Mapa Mental da aplicação Demoblaze, Planejamento e Documentação de Testes Exploratórios  

### 🌀 Sprint 4  
**Temas:** Testes de APIs, Postman, Swagger (PetStore), Mapeamento de Issues  
**Atividades:** Mapa Mental da API PetStore, Collection Postman, Report de Bugs, Challenge com API ServeRest (Plano de Testes, Collection e Mapa Mental)  

### 🌀 Sprint 5  
**Temas:** Git, GitHub, Python, Pytest, Automação de APIs com Robot Framework  
**Atividades:** Criação de Calculadora em Python com TDD, Automação da API Restful Booker com Robot Framework, Relatório de Code Review  

### 🌀 Sprint 6  
**Temas:** AWS EC2, Amazon Q Power Up, Robot Framework para APIs e Cloud Computing  
**Atividades:** Evolução dos testes na Restful Booker + Relatório de Execução, Deploy da API ServeRest em instância EC2, Challenge 2 [em andamento]  

### 🌀 Sprint 7  
**Temas:** Mapeamento de Elementos Web e Automação Web End-to-End com Robot Framework  
**Atividades:**  
- Estratégias de mapeamento no site challenging_dom (em Squad)  
- Mapeamento individual de elementos no site Demoblaze  
- Exercícios de identificação e validação de elementos nos sites livelo.com, divvino.com e google.com  
- Desenvolvimento e execução de um fluxo completo de testes End-to-End com Robot Framework  
- Utilização do estilo de relatório **Mark85** e ambiente configurado com **Node 18**

## Aprendizados Estratégicos

### Planejamento e Organização de Testes
- Criação de planos de teste com clareza, foco em reusabilidade e cobertura.
- Mapeamento visual (mapas mentais) para auxiliar priorização e organização de ideias.

### Testes Manuais e Exploratórios
- Execução de testes exploratórios com análise de risco e documentação baseada em critérios objetivos.
- Priorização de funcionalidades críticas com base em valor de negócio e impacto técnico.

### Automação de Testes
- Automação de APIs RESTful com Robot Framework, aplicando boas práticas de modularização.
- Criação de testes E2E para aplicações web usando estratégias de mapeamento robustas (XPath, CSS selectors, etc).
- Integração de estilos e frameworks (ex: Mark85 + Node 18) para ambientes mais modernos de execução.

### Cloud e Execução em Ambientes Reais
- Deploy e execução de testes automatizados em instâncias EC2 na AWS.
- Aplicação de conceitos de cloud computing para qualidade distribuída.

### Versionamento e Fluxo Técnico de Trabalho
- Git e GitHub como ferramentas de rastreabilidade e code review.
- Participação em squads, refinamentos e troca técnica com colegas e instrutores.

## Considerações Finais

Este repositório não é apenas uma coleção de arquivos: é um registro vivo da minha evolução como profissional de QA em formação, documentando erros, acertos, descobertas, revisões e reflexões técnicas ao longo de cada sprint. A cada entrega, busquei entender não só o "o que fazer", mas principalmente o "como" e "por que fazer" — conectando ferramentas, lógica e contexto de negócio.

O repositório continua em evolução à medida que novas sprints e desafios práticos forem sendo concluídos, com o objetivo de manter uma base sólida de conhecimento e apoiar o compartilhamento com colegas, mentores e a comunidade.
