# Repositório de Materiais de QA e Testes

Este repositório reúne os principais arquivos e materiais produzidos durante meu estágio em Quality Assurance (QA) na Compass Uol, com foco em testes de software, automação e práticas de qualidade. Ele reflete minha trajetória de aprendizado, desde o entendimento de fundamentos teóricos até a aplicação prática em projetos reais, incluindo desafios técnicos, code reviews e uso de ferramentas essenciais para QA moderno.

## Sobre a Jornada de Aprendizado

Durante o estágio, evoluí de conceitos básicos para habilidades avançadas em QA, explorando metodologias ágeis, criação de histórias de usuário, testes manuais, técnicas de priorização, testes exploratórios, API testing, automação com Robot Framework e muito mais. Cada Sprint trouxe novos aprendizados e desafios, e o repositório foi sendo atualizado para refletir esse progresso.

Abaixo, um resumo da evolução das atividades por Sprint:

**Sprint 1**  
- Metodologias Ágeis, User Stories e Refinamento de Requisitos.  
- Atividades: Criação de User Story (Squad) e Mapa Mental da User Story Ideal.

**Sprint 2**  
- Testes de Software, Garantia da Qualidade, AWS (Amazon Q Business, Q Developer, Bedrock).  
- Atividades: Plano de Testes para a aplicação ServeRest e Slides sobre Testes Estáticos (Squad).

**Sprint 3**  
- Testes Baseados em Risco, Priorização, Report de Bugs no Jira e Mapeamento de Aplicações.  
- Atividades: Report Individual de Bugs, Mapa Mental da aplicação Demoblaze, Planejamento e Documentação de Testes Exploratórios.

**Sprint 4**  
- Testes de APIs, Postman, Swagger (PetStore), Mapeamento de Issues.  
- Atividades: Mapa Mental da API PetStore, Collection Postman, Report de Bugs, Challenge com API ServeRest (Plano de Testes, Collection e Mapa Mental).

**Sprint 5**  
- Git, GitHub, Python, Pytest e Automação de APIs com Robot Framework.  
- Atividades: Criação de uma Calculadora em Python com TDD, Automação de Testes na API Restful Booker com Robot Framework, Relatório de Code Review.

**Sprint 6**   
- AWS (Amazon EC2, Q Power Up), Robot Framework para APIs e Cloud Computing.  
- Atividades: Evolução dos testes na Restful Booker + Relatório de Execução, Implementação e Relatório da API ServeRest em uma instância EC2, Challenge 2 [Em Andamento].

## Sobre os Arquivos

Neste repositório, você encontrará:

- **Documentos de Planejamento de Testes**: planos detalhados para diferentes aplicações e desafios.
- **Sessões de Testes Exploratórios**: documentação estruturada de sessões de testes manuais e exploratórios.
- **Mapas Mentais**: representações visuais que apoiam a compreensão e a organização de ideias.
- **Collections Postman**: arquivos para testes de APIs RESTful, como PetStore e ServeRest.
- **Relatórios de Bugs**: registros estruturados de defeitos encontrados durante as atividades.
- **Automação de Testes com Robot Framework**: projetos aplicados a APIs RESTful, como Restful Booker.
- **Code Reviews**: análises críticas de projetos de colegas, aplicando boas práticas de QA.
- **Cloud + QA**: Relatórios e evidências de execução de testes automatizados em ambientes AWS EC2.
- **Outros Materiais Complementares**: slides, esquemas e anotações que apoiaram o desenvolvimento das atividades.

Este repositório não é apenas uma coleção de arquivos: é um registro vivo da minha evolução como QA em formação, documentando erros, acertos, revisões e melhorias ao longo de cada Sprint. Ele serve como base de aprendizado para novos desafios e como um espaço para reflexão e compartilhamento de conhecimento.

À medida que novas atividades forem concluídas, o repositório será atualizado continuamente.
