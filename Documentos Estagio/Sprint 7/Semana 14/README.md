## Projeto de Automação Web – ServeRest

Como parte das atividades práticas de automação, colaboramos em um projeto em squad com foco na aplicação **ServeRest (front-end)**. A automação foi desenvolvida utilizando **Robot Framework** com a **Browser Library**, organizando os testes segundo boas práticas como Page Object Model, reutilização de keywords e separação por áreas funcionais.

> ⚠️ Como este projeto foi realizado de forma colaborativa, foi criado um repositório específico apenas para ele. Todas as implementações e detalhes técnicos estão documentados lá.

🔗 **Repositório do Projeto de Automação Web (ServeRest):**

## Atividade Adicional – Mapeamento HTML da ServeRest

De forma complementar, foi iniciado um **documento de mapeamento de elementos HTML** da aplicação ServeRest, utilizando diferentes abordagens para identificação eficiente de elementos:

* Seletores por `id`, `class`, `atributo` e `texto`
* `XPath` e pseudo-classes CSS
* Critérios de estabilidade, legibilidade e manutenção

Essa atividade não estava inclusa na grade de conteúdos mas foi realizada com o objetivo de aprofundar o entendimento sobre estratégias de automação e qualidade do front-end, visando aprimoramento para as semanas posteriores.
