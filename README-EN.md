## Strategic Learnings

### Test Planning and Organization

* Creating clear test plans focused on reusability and coverage
* Visual mapping (mind maps) to aid prioritization and idea structuring

### Manual and Exploratory Testing

* Executing exploratory tests with risk analysis and objective documentation
* Prioritizing critical features based on business value and technical impact

### Test Automation

* RESTful API automation using Robot Framework with modular best practices
* E2E testing for web apps using robust element-mapping strategies (XPath, CSS selectors, etc.)
* Integration of modern tools (e.g., Mark85 + Node 18) for test execution

### Cloud and Real Environment Execution

* Deployment and test execution in AWS EC2 instances
* Applying cloud computing concepts for distributed quality assurance

### Version Control and Technical Workflow

* Using Git and GitHub for traceability and code reviews
* Participating in squads, refinements, and technical exchanges with peers and mentors
